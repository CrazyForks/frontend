This file is a TrueType conversion of the woff2 shipped by the Songloft
server at internal/jsplugin/assets/fonts/material-symbols-outlined.woff2
(same glyph data, uncompressed container). The conversion exists because
WebF's @font-face implementation does not support woff2 -- see
lib/features/home/presentation/render/plugin_render_fonts.dart for the
full explanation.
